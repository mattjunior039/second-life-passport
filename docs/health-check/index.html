Health CheckMeasured, not typed

💻 Chromebook

Open the launcher, search Diagnostics, and read Battery health and Cycle count from the Battery card. Enter them in the Repair Station.

🪟 Windows / ThinkPad

Download windows.ps1 and run it in PowerShell. It reads design capacity, full-charge capacity and cycle count from Windows (the same data as powercfg /batteryreport) and opens the Repair Station pre-filled.

🍎 Mac

Run in Terminal:

curl -s https://mattjunior039.github.io/second-life-passport/health-check/mac.sh | bash
